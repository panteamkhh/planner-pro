# Changelog

All notable changes to this project are documented here.
The format is based on [Keep a Changelog](https://keepachangelog.com/).

## [1.0.0] - 2026-09-14

### Added
- Offline, zero-dependency bilingual planner (Persian / English).
- Jalali and Gregorian calendar engines with automatic date conversion when switching language (shared data).
- Sections: Dashboard, Today, Week, Month, Goals, Habits, Library, History, Path, Finance, Notes, Weekly Schedule, Stats, Settings.
- Mood tracker (today, notes, history, stats) and 30-day habit tick grid with dates.
- 14 color themes, 5 layout styles, light/dark mode.
- Personalized menu: reorder and hide sections.
- Custom per-category goal/note field.
- JSON backup export/import and demo data.
- Single-file bilingual build (`planner-bilingual.html`) and localhost version (`index.html`).
- In-repo build tooling: `scripts/translate.js`, `scripts/build.js`.
- GitHub Pages workflow and community templates.
